# Security

Report vulnerabilities privately through GitHub private vulnerability reporting on this repository ("Security" tab, "Report a vulnerability"). Do not open a public issue.

In scope: the apps in `apps/`, their signing and release workflow, and secrets handling. Include the app, version, and steps to reproduce.

Signing keystores and passwords are never stored in this repository. If one is exposed, tell the maintainers at once: the key cannot be rotated for already installed apps.
